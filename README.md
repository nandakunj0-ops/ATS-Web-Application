# ATS-Web-Application

## Project Overview
Smart ATS is a web-based Applicant Tracking System developed using Python, Flask, and SQLite.

The application helps recruiters manage job openings, applicant information, job applications, and candidate skill matching through a simple web interface.

## Live Website
https://ats-web-application.onrender.com

## GitHub Repository
https://github.com/nandakunj0-ops/ATS-Web-Application

## Features
- Dashboard with recruitment statistics
- Add and manage job openings
- Add and manage applicant details
- Create job applications
- Update application status
- Candidate skill matching with percentage scores

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- Gunicorn

## How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/nandakunj0-ops/ATS-Web-Application.git
```

2. Open the project folder:

```bash
cd ATS-Web-Application
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
python app.py
```

5. Open this URL in your browser:

```text
http://127.0.0.1:5000
```
